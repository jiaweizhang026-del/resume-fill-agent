# 履历助手商店审核填写材料

以下为待填入后台的草稿，不代表已提交或通过审核。

## 单一用途

根据用户主动提供的履历，辅助填写招聘和网申网页表单。用户在侧边栏发起任务，扩展识别页面字段并执行输入、选择和滚动，用户核对结果并自行提交。

## 权限用途

- storage：在用户浏览器本地保存履历、产品访问 Key 和设置，以便重复使用。
- sidePanel：显示任务输入、执行状态、填写结果和设置。
- tabs：识别任务关联标签页，读取其标题和地址，并在任务需要时切换相关页面。
- tabGroups：组织任务关联的标签页，便于多页面任务中的页面识别与管理。
- 主机权限：招聘表单分布在不同网站，需要访问用户发起填写任务的页面以读取字段、点击、输入、选择及滚动，并向产品模型网关发送完成任务所需的上下文。

## 测试说明

1. 安装扩展并打开“履历助手 Agent”侧边栏。
2. 在设置中输入测试专用产品 Key（应单独填写在后台私密凭据栏，不放在公开说明中）。
3. 粘贴以下虚构测试履历：姓名：测试用户；英文名：Test User；邮箱：test@example.com；教育经历：示例大学，计算机科学本科；技能：JavaScript、HTML、CSS。
4. 打开含姓名、邮箱等字段的可编辑测试表单网页。不要在 chrome:// 页面、Chrome 商店页面或 PDF 阅读器上测试填写。
5. 发送“根据我的履历填写当前页面，不要提交”。观察字段输入和侧边栏执行过程。
6. 核对结果。最终提交由用户自行完成，测试无需实际投递。

需要联网及具有余额的产品 Key；一次任务可能发生多次模型调用。需在提交审核前准备有效的审核专用 Key 和可访问的测试表单地址。
